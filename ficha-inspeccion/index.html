Acciones

"Descargar" guarda el archivo en el teléfono; "Compartir" lo envía por WhatsApp, correo u otra app. El PDF es para imprimir y firmar a mano; el Word (.docx) es el mismo informe pero se puede editar.

Identificación

Lugar

Se completa solo con el centroide del área dibujada. Puedes corregir cualquier campo a mano.

Área de inspección y mapa

Dibuja el área con las herramientas (arriba a la izquierda): rectángulo/cuadrado o polígono de varios vértices. La coordenada UTM se calcula sola desde el centroide del polígono. El botón de ubicación (📍) centra el mapa donde estás, solo para orientarte: no crea ningún punto.
